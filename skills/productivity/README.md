# Productivity

Stable general workflow skills that are not specific to code work.

## User-invoked

None. Every productivity skill is model-invoked.

## Model-invoked

- **[`grilling`](./grilling/SKILL.md)** — Grill the user relentlessly about a plan, decision, or idea.
- **[`unslop`](./unslop/SKILL.md)** — Remove AI writing patterns from prose while preserving meaning and tone.
- **[`wait-what`](./wait-what/SKILL.md)** — Re-pitch a message so it stands on its own: one the user did not follow, or another agent's report before it reaches them.
- **[`writing-for-agents`](./writing-for-agents/SKILL.md)** — Design reliable instructions and documentation for agents.
