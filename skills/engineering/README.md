# Engineering

Stable skills used regularly for code work.

## User-invoked

- **[`bug-hunt`](./bug-hunt/SKILL.md)**: find bugs nobody has reported, fix the easy ones in one draft pull request, and file the rest as issues. It runs to the end on its own.
- **[`retro`](./retro/SKILL.md)**: record evidence-backed lessons from agent runs without changing the workflow.

## Model-invoked

- **[`adr`](./adr/SKILL.md)**: record the reason behind a consequential architecture decision.
- **[`agents-md`](./agents-md/SKILL.md)**: maintain a project's instructions for coding agents.
- **[`architect`](./architect/SKILL.md)**: settle a decision that is costly to reverse, such as a schema, a contract that writes, or a security boundary, with the human.
- **[`coding-standards`](./coding-standards/SKILL.md)**: maintain project rules that need judgment in code review.
- **[`deliver`](./deliver/SKILL.md)**: take an accepted spec to a pull request with green checks.
- **[`diagnosing-bugs`](./diagnosing-bugs/SKILL.md)**: find the root cause of a hard or intermittent failure from a reproduction or runtime evidence.
- **[`garden`](./garden/SKILL.md)**: between features, fix what has drifted in one area, grouped by cause, in one pull request, and file the rest. It runs to the end on its own.
- **[`how`](./how/SKILL.md)**: explain how a system works, from evidence.
- **[`program-design`](./program-design/SKILL.md)**: agree on the shape of the code (modules, types, call paths, errors) before anyone writes it.
- **[`prototype`](./prototype/SKILL.md)**: compare UI directions, or try a logic model in an HTML demo, before committing to a design.
- **[`prune`](./prune/SKILL.md)**: remove the tests and checks in one area that cost more than they protect, and prove every contract still has a test that fails when it breaks.
- **[`refine`](./refine/SKILL.md)**: review a working change as a fresh reviewer and improve it without changing its behavior, in at most three rounds.
- **[`research`](./research/SKILL.md)**: answer a bounded question with a cross-checked report from primary sources.
- **[`setup-verification`](./setup-verification/SKILL.md)**: give agents one way to run and observe the real product, with acceptance tests that run the same locally and in CI.
- **[`shape`](./shape/SKILL.md)**: agree with the human on one spec: what to build, what success means, and how to prove it.
- **[`ship`](./ship/SKILL.md)**: open a draft pull request, drive its checks to green, and answer its review with the smallest fix.
- **[`skill-guide`](./skill-guide/SKILL.md)**: explain the available skills and recommend what to invoke next.
- **[`spike`](./spike/SKILL.md)**: settle one technical question with a small throwaway experiment.
- **[`strategic-programming`](./strategic-programming/SKILL.md)**: design and write maintainable code, and build only what a real case needs.
- **[`walkthrough`](./walkthrough/SKILL.md)**: render a design as a visual page the human reads before accepting it.
- **[`why`](./why/SKILL.md)**: recover why code or a decision has its current shape, from its history.
